# openapi-client (vendored, slimmed)

Generated client for the Digital Bible Platform (DBT) API —
"Fast, easy, and free API access to video, audio, and text
Bibles."

- API version: 4.0.0-beta
- Package version: 1.0.0
- Generated by: https://openapi-generator.tech
  (`org.openapitools.codegen.languages.PythonClientCodegen`)

## How it is used

`bible/services/dbt/client.py` appends this directory to
`sys.path` and imports `openapi_client` directly — the package
is **not** `pip install`ed. Only `BiblesApi` is used through the
generated client (`v4_bible_one`, `v4_bible_books`,
`v4_bible_filesets_show_chapter`); every other DBT endpoint is
called via raw `requests` in `client.py` because several
generated deserializers are buggy.

## Slimmed contents

The generated `setup.py`/`setup.cfg`/`tox`/CI metadata, `test/`
and `docs/` trees were removed (nothing pip-installs this tree),
along with the unused `AnnotationsApi`, `AudioTimingApi` and
`SearchApi` classes. Runtime requirements are pinned in the repo
root `requirements.txt` (`certifi`, `six`, `python-dateutil`,
`urllib3`).
